# Unframe Log v1 — 기록·성취 (설계)

2026-11-16 · 재우님과 정한 방향. Claude Office를 "보기만 하는 사무실"에서 **두 사람의 기록·성취 워크스페이스**로 바꾼다.
영감: Threads @paperlogy_life 영상 — "한 해 365일 가운데 60일", 365점 그리드, 원형 연간 달력, "12달 × 30장 × 35분 = 1,260시간 ÷ 8시간 = 158일" 같은 거대한 숫자 + −/+ 계산기, 밝은/파랑/어두운 3가지 화면 톤.

## 핵심 경험
"아주 짧은 노력이라도 꾸준히 하면 얼마가 되는지"를 **내 실제 기록으로** 보여주고, 개인 기록으로 남겨 성취감을 준다.

## 정해진 것
- 기존 픽셀 사무실은 **작은 탭("오피스")으로 유지** (펫 작은 창·Claude 상태 포함). 새 기록 화면이 첫 화면.
- 1단계 범위: **기록·성취**. 노션형 문서·캘린더·Claude 자동 기록은 2단계 이후.
- 기록 단위 3가지: **시간(분)**, **횟수·개수**(단위 이름 직접: 장·쪽·잔·회), **했다/안 했다**.

## 화면
1. **오늘** (첫 화면)
   - 내 습관 목록 + 한 번 누르기 기록: 분 → `+5 +10 +15 +30` / 개수 → `+1 +5` / 체크 → `했어요`. 잘못 눌렀으면 되돌리기.
   - 오늘 목표 대비 진행 바, 연속 기록(🔥 n일), 오늘 한마디 메모(선택).
   - 상대의 오늘 진행 요약(공개 습관만): "소연님 3/4 완료 🔥12일".
2. **내 기록** (습관 하나를 열면 — 영상 스타일의 핵심 화면)
   - 거대한 누적 숫자: "올해 **48시간**", "누적 **365장**", "**92일** 했어요".
   - **365점 그리드**: 올해 각 날을 점으로, 기록량에 따라 진하기. 오늘 위치 표시. ("365일 가운데 92일")
   - **원형 연간 달력**: 12달이 고리로 도는 365점 (영상 파랑 화면).
   - **"이 속도면" 계산기**: 하루 양 × 주당 일수 × 52주 = 한 해 총량 → 환산(시간 ÷ 8 = 근무일, 쪽 → 책 n권 등). 각 숫자에 −/+ 버튼, 바꾸면 즉시 다시 계산. 기본값은 내 최근 30일 평균.
   - 연속 기록·최장 기록·이번 달·월별 막대.
3. **성취**
   - 업적(배지): 첫 기록, 연속 7/30/100/365일, 누적 시간 10/50/100/500시간, 누적 개수 100/500/1000, 한 달 개근 등. 달성 순간 축하 화면(큰 숫자 + 짧은 애니메이션).
   - **월간·연간 리포트**: 영상처럼 스크롤로 넘기는 스토리 페이지(밝음 → 파랑 → 어두움 톤), 큰 숫자와 계산식. 이미지로 저장(공유용).
4. **함께**: 기존 채팅·화이트보드·확인 요청·업무일지는 이 탭으로 정리(기능 유지).
5. **오피스**: 기존 픽셀 사무실 그대로.

## 데이터 (Firestore, 기존 프로젝트·보안 규칙에 추가)
- `trackers/{id}`: `owner`(멤버 id), `name`, `emoji`, `unit`('minutes'|'count'|'check'), `unitLabel`(개수일 때 '장' 등), `dailyGoal`(숫자, 체크는 1), `color`, `private`(bool, 기본 false), `order`, `createdAt`, `archived`.
- `logs/{owner}__{trackerId}__{YYYY-MM-DD}`: `owner`, `tracker`, `day`, `amount`(분/개수/1), `note`(선택, 200자), `private`(습관의 값을 복사 — 규칙이 문서만 보고 읽기를 막을 수 있게, 규칙이 습관과 같은지 확인), `updatedAt`. 하루 한 문서에 합산(쓰기 절약, `increment`).
- 업적·통계는 클라이언트에서 계산(별도 저장 안 함). 달성 알림을 한 번만 띄우려면 `profiles`에 `seenAchievements` 배열 추가.
- 규칙: 본인만 쓰기. 읽기는 멤버 전체, 단 `private`인 습관과 그 기록은 본인만.
- 비용: 기록 1번 = 쓰기 1번. 하루 수십 번 수준이라 무료 한도 안.

## 디자인
- 영상 톤: 큰 숫자 위주의 에디토리얼 레이아웃, 여백 넓게, 숫자는 좁고 긴 디스플레이 서체(예: Oswald/Big Shoulders 계열) + 본문 Pretendard. 강조색 코발트 블루(#1f3fbf 근처), 화면 톤 3가지(밝음·파랑·어두움).
- 모바일 우선(휴대폰에서 기록이 가장 많음), PWA 그대로. 누르는 순간 숫자가 올라가는 짧은 애니메이션.

## 기술
- 지금처럼 빌드 없는 정적 사이트 + ES 모듈 유지(배포 단순). 새 코드는 `web/log/`에 모듈로 분리, `app.js`는 탭 전환·공통(로그인·스토어)만.
- `?demo`에 가짜 데이터(습관 3~4개, 200일치 기록)로 모든 화면을 확인할 수 있게.
- 보안 규칙은 `scripts/build.js`에 추가 → 게시. 이메일 파일 커밋 금지 규칙(CLAUDE.md) 그대로.

## 완료 기준 (1단계)
- 휴대폰에서 습관을 만들고 한 번 눌러 기록, 365점 그리드·누적 숫자·계산기가 즉시 바뀐다.
- 업적 달성 시 축하 화면, 월간 리포트를 이미지로 저장할 수 있다.
- 기존 기능(채팅·화이트보드·확인 요청·업무일지·오피스)이 탭 안에서 그대로 동작한다.
- 데모 모드로 전 화면 확인, 실제 Firebase 규칙 게시, main 푸시 → Netlify 배포.

## 구현 메모 (1단계, 2026-11-16)
- 코드: `web/log/` — `model.js`(날짜·통계·업적·계산기, 순수 함수), `store.js`(Firestore/데모 저장소, 데모 가짜 데이터), `charts.js`(365점 그리드·원형 달력·월별 막대 SVG), `ui.js`(오늘·내 기록·성취·축하·습관 만들기), `report.js`(월간·연간 스토리 + 1080×1920 PNG 저장), `log.css`.
- `app.js`는 탭 전환(`#today` `#log` `#achieve` `#together` `#office`, 단축키 1~5·N), ⋯ 메뉴, 함께 탭 배지, `startLog()`만 맡는다.
- 연속 기록 = 기록량 > 0인 날이 이어진 수 (오늘 아직 안 했으면 어제까지로 계산). 목표 달성 = 하루 목표 이상(체크는 했으면).
- 업적은 처음 불러올 때 이미 모은 것은 조용히 `profiles.seenAchievements`에 저장(한꺼번에 축하하지 않게), 그 뒤 새로 달성한 것만 축하 화면. `profiles` 저장은 `merge`로 바꿔 꾸미기 저장이 이 값을 지우지 않게 함.
- 데모(`?demo`): 내 습관 4개(독서·글쓰기·스트레칭·🔒기타), 상대 4개(1개 비공개라 안 보임), 약 200일치. 독서는 어제까지 29일 연속 → 오늘 기록하면 30일 연속 축하, 기타는 누적 99시간 50분 → +10분이면 100시간 축하.
