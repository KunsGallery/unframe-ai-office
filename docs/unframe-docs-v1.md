# Unframe Log — 문서 (노션형) + 캘린더 설계 v1

2026-11-16 · 재우님과 정한 것: **블록 편집기**, **평평한 목록 + 태그**(하위 페이지 없음), **실시간 동시 편집 없음**, **이미지는 다음 단계**, 새 문서는 **함께 보기가 기본**, **캘린더도 같이**.

## 화면
- 새 탭 **문서** (성취와 함께 사이). 탭 6개, 휴대폰 아래 탭 바에도 그대로.
- **목록**: 검색(제목+본문), 태그 칩으로 거르기, 정렬(최근 수정 / 만든 순), 📌 고정, "나만 보기 / 함께 보기" 표시. 맨 위 `+ 새 문서`.
- **문서 화면**: 이모지 + 큰 제목, 태그 입력, 공개 범위, 마지막 수정(누가·언제). 아래 블록들.
- 디자인은 기록 화면과 같은 에디토리얼 톤(밝은 종이 배경, Pretendard 본문, Oswald 숫자).

## 블록 편집기 (직접 구현, 외부 라이브러리 없음)
- 블록 = 한 줄짜리 `contenteditable`. Enter 새 블록, 빈 블록에서 Backspace 이전 블록과 합치기, ↑↓ 블록 사이 이동.
- `/` 메뉴로 바꾸기: 본문, 제목 1·2·3, 글머리 목록, 번호 목록, 할 일(체크), 인용, 콜아웃(💡), 구분선, 코드, **습관 카드**(내 습관 하나의 올해 누적 큰 숫자·연속 기록을 실시간으로 보여주는 블록 — 기록 기능과 연결).
- 마크다운 단축 입력: `# ` `## ` `### ` `- ` `1. ` `[] ` `> ` `---` 입력 시 자동 변환.
- 글자 서식: 굵게(⌘B), 기울임(⌘I), 인라인 코드, 링크(⌘K). 저장할 때 `b i code a` 태그만 남기고 나머지는 지움(XSS 방지), 링크는 http(s)만.
- 블록 옮기기: 블록 왼쪽 ⋮⋮ 손잡이 끌기(휴대폰은 길게 눌러 위/아래 메뉴), 블록 메뉴에서 복제·삭제.
- 자동 저장: 입력 멈추고 1초 뒤. 상단에 "저장됨 · 방금".

## 데이터 (Firestore)
- `pages/{id}`: `owner`, `title`(≤100), `emoji`, `tags`(≤10개, 각 ≤20자), `shared`(bool, 기본 true = 함께 보기), `pinned`(bool), `blocks`(배열 `{id, type, text, checked?, tracker?}`, 문서 전체 ≤ 약 900KB), `rev`(int), `createdAt`, `updatedAt`, `updatedBy`.
- 목록은 `blocks` 없이 보이면 좋지만 Firestore는 필드 일부만 읽을 수 없어서, 목록용 요약 `preview`(본문 앞 200자)와 `words`를 문서에 같이 저장하고 목록도 같은 문서를 구독 (두 사람 규모라 읽기 비용 문제 없음).
- **동시 편집 대신 덮어쓰기 방지**: 저장 때 `rev`를 1 올리고, 규칙이 `rev == 이전 rev + 1`만 허용. 상대가 먼저 고쳤으면 저장이 거절되고 "소연님이 방금 고쳤어요 — 새 내용 불러오기 / 내 내용 복사" 안내.
- 규칙: 읽기는 본인 또는 `shared == true`. 만들기·지우기·공개 범위 변경은 본인만. `shared` 문서의 내용 수정은 두 사람 모두.
- 습관 카드 블록은 `tracker` id만 저장하고 화면에서 실시간 계산 (상대의 비공개 습관이면 "볼 수 없는 습관").

## 데모 (`?demo`)
문서 4~5개: 독서 노트(습관 카드 포함), 주간 회고(할 일 블록), 프로젝트 아이디어(태그), 소연님이 공유한 회의 메모.

## 캘린더
- 탭 순서: 오늘 · **캘린더** · **문서** · 내 기록 · 성취 · 함께 · 오피스 (단축키 1~7).
- 한 달 보기(일요일 시작): 날마다 일정(내 것 파랑, 상대 주황, 시간 순 3개 + 더보기), 화이트보드 마감 ⚑, 그날 기록한 내 습관 색 점. 휴대폰은 점으로만.
- 날짜를 누르면(PC는 오른쪽, 휴대폰은 아래) 그날: 일정 추가·수정·삭제(제목·날짜·시간 선택·메모·함께 보기), 내 기록(지난 날도 +/−·했어요로 고치기, 앞으로 올 날은 막음), 상대 공개 습관 기록, 화이트보드 마감, 그날 만든·고친 문서, "○월 ○일 메모" 문서 열기/쓰기(태그 '일지').
- `events/{id}`: `owner`, `title`(≤100), `day`, `time`(''=하루 종일 또는 HH:MM), `note`(≤500), `shared`(기본 true), `createdAt`, `updatedAt`. 읽기는 본인 또는 함께 보기, 함께 보기 일정은 둘 다 고치고 지울 수 있음, 공개 범위는 본인만.
- 반복 일정·여러 날 일정·알림은 아직 없음.

## 이번에 안 하는 것
이미지·파일 첨부(다음 단계 — Firestore에 줄여 저장 또는 Blaze 전환 중 결정), 하위 페이지, 실시간 동시 편집, 데이터베이스/표 보기, 휴지통(삭제는 확인 후 바로 삭제), 반복 일정.

## 완료 기준
- 휴대폰·PC에서 문서를 만들고 `/` 메뉴로 블록을 바꾸고, 자동 저장 후 새로고침해도 그대로.
- 태그·검색으로 찾기, 함께 보기 문서를 상대가 읽고 고칠 수 있고, 동시에 고치면 덮어쓰지 않고 안내.
- 기존 탭(오늘·내 기록·성취·함께·오피스) 그대로 동작, 규칙 게시, main 푸시.
