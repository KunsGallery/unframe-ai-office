          ❓ 도움말
          
  
          
    
          Claude Office는 우리 팀의 Claude Code 작업을 픽셀 사무실로 보여주고, 메시지·할 일·확인 요청·업무일지를 한곳에서 쓰는 사무실이에요.
          

    
          ⌨️ 단축키
          
    
          
      
          ?도움말 열기·닫기
          
      
          M메시지 입력칸으로
          
      
          Enter / Shift+Enter메시지 보내기 / 줄 바꾸기
          
      
          B화이트보드(할 일 추가)
          
      
          R확인 요청 보내기
          
      
          J업무일지
          
      
          L꾸미기 (내 모습·내 Claude·내 펫)
          
      
          P사무실 작은 창 띄우기
          
      
          Esc열린 창 닫기
          
    
          
    
          입력칸에 글을 쓰는 중에는 단축키가 동작하지 않아요.
          

    
          🏢 사무실 읽는 법
          
    
          
      
          📚 자료실Claude가 파일을 읽거나 검색하는 중
          
      
          ⌨️ 작업실코드를 고치는 중 (모니터가 켜져요). 앞쪽 책상은 사람 자리
          
      
          🖥 서버실명령을 실행하는 중 (테스트·빌드·커밋)
          
      
          📡 통신실웹을 조사하는 중. 사람은 회의할 때 여기 앉아요
          
      
          ☕ 라운지일을 끝내고 쉬는 중
          
      
          🛗 엘리베이터출근·퇴근
          
      
          흰 이름표사이트를 열어둔 사람
          
      
          🤖 ○○의 Claude그 사람의 Claude. 옆에 지금 쓰는 도구가 보여요
          
      
          ↳ 노란 이름표Claude가 일을 나눠 맡긴 보조 작업자(서브에이전트)
          
      
          노란 "…" 말풍선Claude가 승인을 기다리는 중 — 맡긴 사람이 터미널에서 승인해야 진행돼요
          
      
          초록 체크방금 작업을 끝냈어요
          
      
          📌답을 기다리는 확인 요청을 보낸 사람
          
    
          

    
          🚶 걸어 다니기
          
    
          사무실 바닥을 클릭(휴대폰은 탭)하면 내 캐릭터가 걸어가요. 도착한 곳에 따라 기능이 실행돼요.
          
    
          
      
          상대 옆채팅창이 열리고 "똑똑" 인사말이 준비돼요. Enter로 보내요
          
      
          화이트보드 앞할 일 목록으로 이동
          
      
          자료실업무일지 열기
          
      
          통신실"회의 중"이 되고 회의 초대를 보낼지 물어요. 두 사람 모두 회의 중이면 📝 회의 메모 칸이 열려요
          
      
          라운지"휴식"이 되고 커피 초대를 보낼지 물어요
          
      
          작업실"근무 중"으로 돌아와요
          
    
          
    
          상태 메뉴를 직접 바꾸면 캐릭터가 그 상태의 자리로 돌아가요. 내 캐릭터를 누르면 꾸미기, 상대를 누르면 채팅이 열려요.
          

    
          💼 내 상태
          
    
          근무 중 · 회의 중 · 🎧 집중(메시지·요청 알림을 잠시 끔, 내 Claude 알림은 유지) · ☕ 휴식 · 외근·퇴근(사무실에서 나감). 사이트를 닫으면 2~3분 뒤 자동으로 퇴장해요.
          

    
          📋 화이트보드 · 🙋 확인 요청 · 📓 업무일지
          
    
            
      
          • 화이트보드: 할 일에 담당자·마감일을 정해요. 마감 지난 일은 빨간색, ✎로 수정, "내 담당"만 보기. 체크하면 바로 확인 요청을 보낼 수 있어요.
            • 
      
          • 확인 요청: 내용과 미리보기 링크를 보내면 상대가 "확인 완료 / 수정 필요"로 답해요. 요청과 답은 채팅에도 남아요.
            • 
      
          • 업무일지: 날짜를 고르면 사람·프로젝트별 작업, 커밋, 회의 메모, 할 일, 확인 요청이 자동으로 정리돼요. ✨ AI 요약, 복사, 채팅으로 보내기.
            • 
    
          

    
          🎨 꾸미기 · 🐾 펫
          
    
          내 모습, 내 Claude의 모습과 이름, 내 펫(보더콜리·허스키·골든 리트리버·치와와·고양이·토끼)과 펫 이름을 골라요. 두 사람 화면에 똑같이 보여요. 펫은 주인을 따라다니고, 누르면 하트를 보내요.
          

    
          📺 작은 창
          
    
            
      
          • 🏢 사무실 띄우기: 사무실이 항상 맨 위에 떠 있는 작은 창으로 보여요. 창 안에서도 클릭할 수 있어요.
            • 
      
          • 🐾 내 펫 띄우기: 내 펫이 크게 보이고, 내 Claude 상태를 펫이 알려줘요 — 일하는 중엔 돌아다니고, 승인을 기다리면 "…"를 띄우며 폴짝폴짝, 작업이 끝나면 하트, 쉴 땐 앉아 있어요.
            • 
      
          • 작은 창은 한 번에 하나만 열 수 있고, Chrome·Edge에서 동작해요 (Safari는 사무실 보기만 가능).
            • 
    
          

    
          🔔 알림 · 📲 앱 설치 · 🔌 내 PC 연결
          
    
            
      
          • 알림을 켜면 새 메시지, 확인 요청, 맡겨진 할 일, 내 Claude의 승인 대기(5·15분 뒤 재알림)·완료를 소리와 화면 알림으로 알려줘요.
            • 
      
          • 앱 설치: 휴대폰·PC 홈 화면에 아이콘을 만들어요 (아이폰은 Safari 공유 → 홈 화면에 추가).
            • 
      
          • 내 PC 연결: 명령을 복사해 터미널에 붙여넣으면 내 Claude Code가 사무실에 출근해요. 연결 코드는 다른 사람에게 보내지 마세요.
            •
